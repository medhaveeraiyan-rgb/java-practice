# Basics Java Programs

This folder contains beginner-friendly Java programs that demonstrate the fundamental concepts of Java programming. The programs are organized into different topics to make learning structured and easy to follow.

## Topics Covered

### Basics

* `Factorial.java` – Calculates the factorial of a number.
* `PrimeNumber.java` – Checks whether a number is prime.
* `FibonacciSeries.java` – Generates the Fibonacci sequence.

### Arrays

* `LargestElement.java` – Finds the largest element in an array.
* `SumOfArray.java` – Calculates the sum of all elements in an array.

### Strings

* `PalindromeString.java` – Checks whether a string is a palindrome.

### OOP (Object-Oriented Programming)

* `Student.java` – Demonstrates classes, objects, and constructors.
* `InheritanceDemo.java` – Demonstrates inheritance using parent and child classes.

### Collections

* `ArrayListDemo.java` – Demonstrates basic operations using `ArrayList`.
* `HashMapDemo.java` – Demonstrates storing and retrieving key-value pairs using `HashMap`.

### Exception Handling

* `TryCatchDemo.java` – Demonstrates exception handling using `try` and `catch`.
